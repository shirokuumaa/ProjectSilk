## Функция работает от начала до конца

Покупатель вводит обмеры → видит своё тело → добавляет вещь в Гардероб →
надевает её → вещь облегает фигуру → видит вердикт по размеру и зоны натяжения.

**Ключевой принцип:** аватар — это тело покупателя, построенное из его замеров.
Одежда не растягивается под фигуру. Если вещь не сходится — приложение говорит об этом.

## Решения, которые не стоит пересматривать

1. **Аватар хранится как числа.** ~200 байт против ~20 МБ, мгновенная загрузка,
   работает на любом устройстве, никаких артефактов генерации.
2. **Тело строится формулой.** Обмеры соблюдаются точно, а не приблизительно.
   Прижатие ткани считается аналитически — Blender и GPU не нужны.
3. **Подбор размера — арифметика прибавок,** не нейросеть. Объяснимо и проверяемо.
4. **Одежда масштабируется по ширине тела,** не по росту.
5. **Художественная модель — последний слой,** а не первый.

```bash
cd ~/ProjectSilk/server && npm start   # 5050
cd ~/ProjectSilk/client && npm start   # 3000

# данные
docker exec projectsilk-mongo mongosh projectsilk --quiet --eval "db.bodyprofiles.find().pretty()"
docker exec projectsilk-mongo mongosh projectsilk --quiet --eval "db.products.find({}, {title:1, garmentType:1, sizeChart:1}).pretty()"
```

Прижатие ткани пишет в консоль браузера, сколько вершин двинулось —
если там нули, значит модель одежды не попала в зону тела.

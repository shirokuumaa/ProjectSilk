# Болванка своими руками — без художника и без денег

Дата: 14 сентября 2026
Проект: ProjectSilk

---

## Почему это вообще возможно

Мы полгода считали художника главным блокером. Это была ошибка: в твоём же
раннем документе `tryon-avatar-plan.md` решение №2 гласит — «базовое тело —
параметрическая модель, не заказ художнику, брать MakeHuman / MPFB2».
Более поздний документ это перебил, и блокер оказался придуманным.

**MPFB2** — бесплатный опенсорсный генератор людей, работающий внутри Blender.
Он даёт готовое человеческое тело с сотнями параметрических настроек, скелетом,
кожей, волосами и — ключевое — **добавляет параметры как shape keys**, а не
запекает их в неподвижный меш. Морф-таргеты, которые мы собирались заказывать,
там уже есть.

Реалистичный срок для человека, впервые открывающего Blender: **3–5 дней**
на болванку и ещё **1–2 дня** на калибровку. Не недели.

---

## Что нужно установить

| Что | Где | Цена |
|---|---|---|
| Blender 4.2 или новее | blender.org | бесплатно |
| MPFB2 | github.com/makehumancommunity/mpfb2 → Releases → `.zip` | бесплатно |

Установка MPFB2: Blender → Edit → Preferences → Add-ons → Install from Disk →
выбрать скачанный `.zip` → поставить галочку. В боковой панели 3D-вида
(клавиша `N`) появится вкладка **MPFB**.

---

## Шаг 1. Создать базовое тело

1. Вкладка MPFB → **New Human**
2. Режим: **From scratch**
3. Важно: включить опцию, при которой таргеты добавляются **как shape keys**
   (не «baked mesh»). Если меш запечён, морфов не будет и всё насмарку.
4. Пол — женский (основная аудитория), возраст — взрослый
5. Все ползунки оставить в среднем положении. Это наш «нулевой» человек

На выходе: тело в A-позе, около 13–14 тысяч вершин. Это укладывается
в наши 15 000 треугольников из техзадания.

---

## Шаг 2. Найти нужные морфы

В MPFB2 категория **Measure** — это и есть обмеры. Там ползунки вида
«обхват груди больше/меньше», «талия больше/меньше», «бёдра больше/меньше».

Нам нужны шесть пар:

| Наш морф | Что крутить в MPFB2 |
|---|---|
| рост | Macro → Height |
| обхват груди | Measure → bust circumference |
| талия | Measure → waist circumference |
| бёдра | Measure → hips circumference |
| ширина плеч | Measure → shoulder distance |
| полнота | Macro → Weight |

Плюс две длины, которые уже считает `BodyProfile.toMorphTargets()`:
длина рук и длина ног — тоже есть в Measure.

**Каждый обмер — это пара морфов** (в плюс и в минус от среднего).
Так и нужно: наш код отдаёт значение 0…1, где 0.5 — среднее телосложение.

---

## Шаг 3. Выбросить лишнее — это обязательно

Главная ловушка. MPFB2 добавляет **сотни** shape keys. Если экспортировать
всё, `.glb` будет весить десятки мегабайт и грузиться полминуты.

1. Свойства объекта → Object Data → **Shape Keys**
2. Удалить все, кроме наших 12–16
3. Переименовать оставшиеся в стабильные имена — код будет искать их
   по строке, поэтому имена менять потом нельзя:

```
height_incr     height_decr
bust_incr       bust_decr
waist_incr      waist_decr
hips_incr       hips_decr
shoulder_incr   shoulder_decr
weight_incr     weight_decr
```

Проверь после удаления: подвигай каждый оставшийся ползунок от 0 до 1 и
убедись, что тело меняется предсказуемо и не выворачивается наизнанку.

---

## Шаг 4. Скелет

MPFB2 → **Rigging** → добавить риг.

Выбирай **Game engine** или **Default no toes** — не Rigify.
Rigify делает управляющие кости для анимации, они нам не нужны и только
раздувают файл. Нужен простой humanoid-скелет с весами скиннинга:
к нему потом будет привязываться одежда переносом весов.

Веса MPFB2 расставляет сам. Проверить: выбрать кость руки в Pose Mode,
повернуть — рука должна двигаться, а платье потом будет двигаться с ней.

---

## Шаг 5. Голова, волосы, кожа

По раннему решению лицо не влияет на посадку одежды, поэтому не увлекайся.

- **Кожа**: MPFB2 → Materials → любой базовый skin. Или однотонный материал
- **Волосы**: MPFB2 → Assets → Hair. В библиотеке MakeHuman есть бесплатные
  причёски. Возьми 6–8 штук, экспортируй каждую отдельным `.glb`
- **Лицо**: категория Face в MPFB2 — те же shape keys. Возьми 8–10 штук
  (ширина лица, челюсть, нос, глаза) тем же способом, что и тело

Волосы и лицо можно отложить: болванка без них уже разблокирует всю работу.

---

## Шаг 6. Экспорт

File → Export → **glTF 2.0 (.glb)**

Обязательные галочки:
- **Include → Selected Objects** (тело + скелет, без камеры и света)
- **Data → Mesh → Apply Modifiers** — выключить, иначе shape keys потеряются
- **Data → Shape Keys** — включить
- **Data → Skinning** — включить
- **Compression (Draco)** — выключить. Наш `GlbViewer` сейчас грузит GLB без
  Draco-декодера, сжатый файл просто не откроется

Целевой размер файла: до 5 МБ. Если больше — остались лишние shape keys.

Положить в `client/public/models/base_avatar.glb`.

---

## Шаг 7. Калибровка — самый важный шаг, и его легко пропустить

Ползунки MPFB2 относительные: «больше» и «меньше», а не «92 сантиметра».
А весь наш продукт построен на обещании, что обхват груди 92 означает ровно 92.
Без калибровки болванка будет красивой и врущей.

Что нужно: для каждого морфа замерить, какому реальному обхвату в сантиметрах
соответствует значение 0 и значение 1. Получится таблица, по которой код
переводит сантиметры покупателя в значения морфов.

Делается скриптом в Blender: секущей плоскостью на нужной высоте берём контур
меша и считаем его периметр — при морфе 0 и при морфе 1. Между ними
интерполируем линейно; на практике ошибка выходит меньше сантиметра.

**Скрипт я напишу** — скажи, когда дойдёшь до этого шага.

Проверка: выстави обмеры реального человека, экспортируй, замерь болванку
портновской лентой в Blender. Расхождение больше 1.5 см — калибровка кривая.

## Шаг 8. Подключить в приложение

Сейчас тело строится процедурно в `client/src/components/BodyAvatar.jsx`
из эллиптических сечений. Его **не удалять**: это рабочий запасной вариант,
и он математически точен по обмерам.

План замены:
1. Новый компонент `BaseAvatar.jsx` — грузит `base_avatar.glb`, выставляет
   `morphTargetInfluences` по таблице калибровки
2. Правило пересчёта: значение `v` из `toMorphTargets()` в диапазоне 0…1
   - `v > 0.5` → влияние ключа `*_incr` = `(v − 0.5) × 2`
   - `v < 0.5` → влияние ключа `*_decr` = `(0.5 − v) × 2`
3. В `GlbViewer` добавить переключатель: процедурное тело или болванка
4. Убедиться, что `FitCamera` кадрирует её так же — он меряет реальные
   границы, так что должен подхватить без правок
5. Когда болванка себя покажет — сделать её по умолчанию

---

## Чего ожидать честно

**Получится хорошо:** тело с правильными пропорциями и обмерами, нормальной
топологией, скелетом и весами. Достаточно, чтобы переносить на него веса
одежды и показывать покупателю.

**Получится средне:** кожа и лицо будут «как в MakeHuman» — узнаваемо
компьютерные. Для примерочной это не важно, покупатель смотрит на платье.

**Не получится:** художественной красоты авторской болванки. Если проект
пойдёт и появятся деньги — художника можно нанять позже, ничего переделывать
не придётся: формат тот же GLB с теми же именами shape keys.

---

## Если Blender совсем не пойдёт

Запасной вариант — оставить процедурное тело из `BodyAvatar.jsx`. Оно уже
работает, точно по обмерам и ничего не стоит. Выглядит как манекен, но
примерку и подбор размера обслуживает полностью. Проверять гипотезу можно
и на нём: покупателя убеждает правильный размер, а не красота манекена.

# Аксессуары, бижутерия, обувь и сумки на аватаре (шаг C)

## 1. Модель «фото → 3D»: сравнение по документации (29.10.2026)

Нужно: из фото товара продавца получить твёрдую 3D-модель (GLB с текстурой). Модель запускается один раз при загрузке товара, на видеокарте. Покупатель за это не платит. Масштаб модели всё равно берём из карточки товара (п. 2), поэтому модели нужно дать только форму и вид, без размеров.

| Модель | Лицензия кода и весов | Коммерция по всему миру | Выход | Видеокарта | Время на предмет (по документации) |
|---|---|---|---|---|---|
| **TRELLIS.2-4B** (Microsoft, дек. 2025) | MIT | да, но см. зависимости ниже | сетка + PBR: цвет, шероховатость, металл, **прозрачность**; GLB с текстурой 4096 | NVIDIA ≥ 24 ГБ, проверено на A100/H100; только Linux | H100: 512³ — 3 с, 1024³ — 17 с, 1536³ — 60 с |
| **TRELLIS** (v1, дек. 2024) | MIT | да, но см. зависимости | сетка с текстурой, гауссианы | NVIDIA ≥ 16 ГБ (A100, A6000) | не указано |
| **Stable Fast 3D** (Stability AI) | Stability AI Community License | **бесплатно, пока годовая выручка ≤ $1 млн**; выше — Enterprise-лицензия Stability | сетка с UV, мало треугольников, снятие освещения, шероховатость и металл на весь предмет | ~6 ГБ; на Mac (MPS) — экспериментально | «меньше секунды» |
| **SPAR3D** (Stability AI) | та же Community License | так же, ≤ $1 млн | как у SF3D, через облако точек | ~10 ГБ* | ~1 с* |
| **TripoSR** (Stability + Tripo) | MIT | да | сетка с цветом в вершинах, без UV | ~6 ГБ | < 1 с |
| **TripoSG** (VAST) | MIT (код и веса) | да | **только форма**, без текстуры | ≥ 8 ГБ | не указано |
| **Hunyuan3D 2.1** (Tencent) | Tencent Hunyuan 3D 2.1 Community License | **нет**: территория лицензии — весь мир, **кроме ЕС, Великобритании и Южной Кореи**; при > 1 млн MAU нужна отдельная лицензия Tencent | сетка + PBR | форма 10 ГБ, текстура 21 ГБ, вместе 29 ГБ | не указано |
| **Step1X-3D** (StepFun) | Apache 2.0 | да, но текстурная часть взята из Hunyuan3D 2.0 (`custom_rasterizer`) — её лицензия под вопросом | GLB с текстурой и без | ~27–29 ГБ | 152 с (50 шагов) |
| **SAM 3D Objects** (Meta, нояб. 2025) | SAM License | да: без порогов выручки; запрещены военное применение и страны под санкциями | гауссианы и сетка | **≥ 32 ГБ**; доступ к весам по заявке | не указано |

\* По памяти, по документации не сверялось — в тест SPAR3D не берём.

### Скрытые ограничения в зависимостях (важно для продажи, не для теста)

- **nvdiffrast** (NVIDIA Source Code License): только некоммерческое использование — «for research or evaluation purposes only». Через него TRELLIS.2 запекает текстуру в GLB (`o_voxel/postprocess.py`, `to_glb`), то же у TRELLIS v1. **Для теста можно** (это evaluation). Для продажи запекание нужно заменить: наш растеризатор UV, `pytorch3d` (BSD), запекание на CPU или лицензия NVIDIA.
- **RMBG-2.0** (BRIA): CC BY-NC 4.0, коммерция только по договору с BRIA. Через него TRELLIS.2 убирает фон (`pipeline.json`, `rembg_model`). Для продажи — исходный **BiRefNet (MIT)** той же архитектуры, или фон, уже убранный при загрузке фото.
- **DINOv3** (Meta, DINOv3 License): коммерция разрешена, но нужна надпись **«Built with DINOv3»** в документации или на странице продукта. Через него TRELLIS.2 читает картинку. Веса — по заявке на Hugging Face.
- У Stable Fast 3D свой запекатель текстуры (CUDA и Metal), фон убирается пакетом `rembg` (u2net). nvdiffrast там не нужен.

### Твёрдые предметы — чего ждать

- **Тонкое** (цепочки, дужки очков, тонкие ремешки часов, кольца) — слабое место всех моделей с одного фото: дужки слипаются, цепочка выходит сплошной лентой. Поэтому:
  - **колье и цепочки** не восстанавливать по фото: цепочка — трубка по линии шеи длиной из карточки, по фото берётся только подвеска;
  - **кольцо** — тор по размеру кольца, по фото берётся только камень или верх;
  - **очки** — главный тест на тонкие детали и прозрачность. У TRELLIS.2 есть прозрачность в материале, у SF3D её нет.
- **Объёмное** (сумка, обувь, шапка, корпус часов): по примерам в статьях хорошо работают TRELLIS.2 и Hunyuan3D; SF3D даёт гладкую форму с мягкими деталями; TripoSR — заметно хуже, «капля» (так и в нашем `docs/TRYON_REVIEW.md`, A6).
- Обратная сторона предмета (подошва, задник, внутренность сумки) моделью придумывается. Для примерки это допустимо: на теле она не видна.

### Выбор для теста

1. **TRELLIS.2-4B** — основной кандидат: лучшее качество, PBR с металлом и прозрачностью, MIT. Цена: ≥ 24 ГБ видеопамяти. Две замены перед продажей: запекание текстуры без nvdiffrast и BiRefNet вместо RMBG-2.0.
2. **Stable Fast 3D** — дешёвый и быстрый для сравнения: 6 ГБ, меньше секунды, своё запекание. Бесплатен, пока выручка меньше $1 млн; дальше лицензия или замена на TRELLIS.2.

Не берём:
- **Hunyuan3D 2.1** — нельзя продавать в ЕС, Великобритании и Южной Корее.
- **Step1X-3D** — неясная лицензия текстурной части, 152 с на предмет.
- **SAM 3D Objects** — 32 ГБ, веса по заявке, вывод в основном гауссианы. Запасной вариант, если TRELLIS.2 не справится с обувью и сумками.
- **TripoSR** уже подключён в проекте (`fastapi_app`), но качество — «капля»; в тест не берём.

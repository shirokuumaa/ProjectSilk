# ProjectSilk — правила работы

## Общение и интерфейс
- Со мной общаться по-русски.
- Весь текст интерфейса (то, что видит покупатель или продавец) — только на английском.
- Цвета — только через `client/src/styles/tokens.css`, без новых захардкоженных значений.

## Продукт
- Рынок — весь мир, глобальная платформа как Amazon, не только постсоветские страны. Закладывать разные валюты, языки и страны. Запуск — пилот на одном рынке.
- Сайт делаем для компьютера; мобильное приложение — после завершения сайта.
- AR должен работать и с веб-камерой компьютера.
- Постоянный GPU не держим, пока нет клиентов.

## Код
- Перед правками показывать план.
- Перед написанием нового искать готовое в проекте и переиспользовать.
- `client/src/components/BodyAvatar.jsx` не удалять.
- Папку `seller/` не трогать.
- Мёртвый код не удалять без моей просьбы.

## Процессы
- Мои сервер (порт 5050) и клиент (порт 3000) не останавливать никогда.
- Для своих проверок поднимать отдельные экземпляры с тестовой базой:
  - сервер: `PORT=5055 MONGODB_URI=mongodb://localhost:27017/projectsilk_authtest CORS_ORIGINS=http://localhost:3011 node index.js` (в `server/`);
  - клиент: `PORT=3011 REACT_APP_API=http://localhost:5055 BROWSER=none npm start` (в `client/`).
- Останавливать только процессы, которые запустил сам, — по номеру процесса, предварительно проверив его (`ps`, `lsof`). Не убивать «всё, что слушает порт».
